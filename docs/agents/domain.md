# Domain Docs

Single-context repo. Before exploring, read `GLOSSARY.md` and any `docs/adr/` entry touching the area you change. If one is missing, proceed silently.

- Use the glossary's terms in issues, tests and proposals; skip the synonyms it lists under _Avoid_.
- Surface a contradiction with an ADR explicitly rather than overriding it.
- API facts (endpoint, IDs, period shapes) are in `docs/agents/api-notes.md`.
